# SeleniumBasic Edge Driver Updater

SeleniumBasic lets Excel VBA control a web browser, but it stops working whenever Microsoft Edge updates and the driver falls out of date. This repository keeps the Edge driver in sync with one click.

## Contents

| File | Purpose |
|---|---|
| Selenium edge driver Update.py | Downloads the Edge driver that matches your installed Edge version |
| UpdateDriver.Bat | Runs the updater with a double click |
| SeleniumBasic-2.0.9.0.exe | SeleniumBasic installer |
| msedgedriver.exe | Edge driver build |

## How to use

1. Install SeleniumBasic.
2. Run UpdateDriver.Bat whenever Edge updates or your VBA macro reports a driver version error.
3. Reopen Excel and run your macro again.
